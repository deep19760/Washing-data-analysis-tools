# 洗衣机运行周期数据分析工具

前后端分离的洗衣机遥测数据分析工具：上传数据文件，自动识别洗涤周期相位节点，计算能耗水耗并绘制时序图。支持「能效」和「程序检查」两种测试类型。

## 使用方法

1. 启动服务：`node backend/server.mjs`
2. 浏览器打开 http://localhost:3000
3. 选择测试类型（能效 / 程序检查），拖入数据文件。

## 测试类型

### 能效分析

上传能效测试数据（含功率、累计用水量、累计电量），识别相位节点、计算能耗水耗、绘制时序图。

输出：相位节点表、总运行时间、总电量、总用水量、主洗时长/用水量/用电、各次漂洗水量/时长/用电、加热时长、最终脱水时长。

### 程序检查分析

上传程序检查数据（含主洗阀电流、排水泵电流、温度、转速、功率），识别主洗涤/漂洗/脱水阶段。

输出：洗涤时间、温度、漂洗次数、总漂洗时间、脱水时间、最高转速、总运行时间。

## 技术栈

- 前端：原生 HTML + JavaScript（Canvas 绘图）
- 后端：Node.js（零 npm 依赖：原生 http + 内置 TextDecoder + 项目内 SheetJS）

## 目录结构

```
backend/
  server.mjs                    # HTTP 服务（GET 静态前端 + POST /analyze）
  analyzer/parse.mjs            # 能效数据解析（GBK/Excel，列名自动映射）
  analyzer/efficiency.mjs       # 能效算法（detectNodes / calcParams）
  analyzer/program-check.mjs    # 程序检查算法（主洗/漂洗/脱水判定）
frontend/index.html             # 前端页面
lib/xlsx.full.min.js            # SheetJS（Excel 解析）
```

## 数据格式

### 能效数据

- Excel（`.xls` / `.xlsx`）或文本（`.tsv` / `.csv` / `.txt`），GBK / UTF-8 自动识别
- 必备字段（列名自动匹配）：时间戳、功率(W)、累计用水量(L)、累计电量(kWh)
- 可选字段：加热器电流(A)、转速(rpm)
- 采样间隔：支持 1 s 与 0.5 s

### 程序检查数据

12 列 GBK 制表符文本（伪装 `.xls`），固定列位（0-based）：

| 列 | 字段 |
|---|---|
| 0 | 时间戳 |
| 1 | 主洗阀电流（代表进水） |
| 2 | 预洗阀电流 |
| 3 | 排水泵电流（代表排水） |
| 4 | 主电机电流 |
| 5 | 加热器电流 |
| 6 / 7 | 温度1 / 温度2 |
| 8 | 转速 |
| 9 / 10 | 电流 / 电压 |
| 11 | 功率 |

## 算法规则摘要

### 能效（efficiency.mjs）

- **有效水表选择**：按进水脉冲谱选择有完整周期变化的水量列；单水表机型禁用第二水表。
- **mainStart**：有效水表首个 `dW > 0.001`。
- **加热段**：首个/末个 `P > 1000W`；低功率加热有滚动窗回退 + 加热器电流闸门。
- **漂洗进水**：进水 burst ≥0.3 L，节点 = 脉冲前 1s；含保温补水切除、漂洗内补水合并、均匀性自检。
- **最终脱水开始**：排水静默→电机启动，含四级回退与二次静默扫描。
- **运行结束**：连续静默 + 平台预检/脉冲回退。

### 程序检查（program-check.mjs）

- **主洗涤结束**：排水泵电流首次大幅上升（相对基线 1.5 倍，30s 内 ≥3 样本）。
- **加热段**：功率 > 1000W。
- **温度**：加热结束时刻的可用温度列（剔除全零/异常列）。
- **漂洗次数**：主洗结束后的主洗阀电流进水段数。
- **最终脱水**：最后一段转速 ≥300 的连续段，加速起点往前回溯。
- **运行结束**：转速<60 且功率<5W 持续 10s。
