# 洗衣机运行周期数据分析工具

纯前端、可离线运行的单文件工具：上传洗衣机采集的遥测数据，自动识别一个完整洗涤周期的相位节点（进水 / 加热 / 漂洗 / 脱水等），计算能耗水耗并绘制时序图。全程本地解析，数据不上传。

## 使用方法

直接双击 `洗衣机数据分析软件.html`（或 `启动洗衣机分析工具.bat`）即可打开，无需联网、无需安装。

页面加载后：点击选择或拖入数据文件 → 自动分析并出图。支持重新分析（自审查）按钮，可反复切换文件或改编码重跑。

## 支持的数据格式

- 文件类型：Excel（`.xls` / `.xlsx` / `.xlsm`）或文本（`.tsv` / `.csv` / `.txt`）
- 编码：GBK 或 UTF-8（自动识别，也可手动指定）
- 必备字段（列名自动匹配，无需手工指定列号）：
  - 时间戳（`yyyy/M/d HH:mm:ss` 或 `yyyy/M/d HH:mm:ss.ffffff`）
  - 功率（W）
  - 累计用水量（L）
  - 累计电量（kWh）
- 可选字段：加热器电流（A）、转速（rpm）等，用于加热判定复核
- 采样间隔：支持 1 s 与 0.5 s（0.5 s 文件自动降采样到 1 Hz）

## 输出

- 相位节点表：运行开始 / 主洗进水开始 / 加热开始·结束 / 各次漂洗进水 / 最终脱水开始·结束 / 运行结束
- 参数：总运行时间、总电量、总用水量、主洗时长·洗涤用水·洗涤用电、各次漂洗用水量、最终脱水时长、加热时长
- 三面板时序曲线：功率 / 累计用水量 / 累计电量
- 自审查：逐相位时间段判定 + 时长 / 水量 / 电量闭合校验 + 漂洗均匀性校验

## 算法判定规则

### 1. 有效水表选择

对两列用水量分别统计进水脉冲谱，选择有完整周期变化的一列；另一列若是开机孤立跳变则排除。单水表机型（表头列名无 `1/2` 编号）强制禁用第二水表，防止误读相邻通道。

### 2. mainStart（主洗开始）

有效水表的首个 `dW > 0.001` 样本。

### 3. 加热段

- 主线：首个 / 末个 `P > 1000 W` 样本。
- 低功率加热（全程无 `P>1000` 时，规则⑩）：60 s 滚动窗内 `>450 W` 样本 ≥18 个视为通电，相邻窗间隔 ≤120 s 合并；满足「段跨 ≥120 s、≥2 段、首末通电点总跨 ≥600 s、通电样本合计 ≥300」才判为温控加热。
- 加热器电流闸门：若文件含「加热器电流」列且通电段内峰值 <1 A，判定加热器未通电（高功率脉冲为电机负载），不设加热段。

### 4. 漂洗进水

进水 burst 中单段进水量 ≥0.3 L 的脉冲；**节点 = 该脉冲前 1 s**（阀门开启时刻）。随后三道后处理：

- 主洗保温补水切除：加热结束后按「最大间隔 ≥30 min 且前段体积 < 后段最大体积 25%」切除前段小补水；
- 漂洗内补水合并：相邻脉冲起始间隔 ≤120 s 且较小体积 < 较大体积 25% 者合并为同一次漂洗；
- 均匀性自检：单段体积 < 最大段 50% 者剔除；相位时长 >2×中位数且体积 < 最大段 60% 者剔除（水量并入主洗）。

### 5. spinStart（最终脱水开始）

末次进水后捕捉「排水静默（`P≤5 W` 且 ≥2 s）→ 电机启动」段：静默后 12 s 内 ≥90 W 且静默后 25~40 s 内再 ≥90 W，取静默段中点；探测上限为首个 `P>300 W` 样本之前。回退链：

1. 排水结束后首个持续电机启动段（连续 ≥3 样本 P≥90、25 s 窗内 ≥20 个 ≥90，且其后 25~300 s 出现 P>300）；
2. `P>80` 且 25 s 后 `P>300` 升速点；
3. 无 P>300 机型（如热泵洗烘）：`P>20` 且其后 180 s 内无 ≥8 s 连续 `P≤10` 回落；
4. 无显著脱水机型：`P≥30` 且其后 60 s 内峰值 ≥60。

另有二次静默扫描（上限改为「首个持续高功率段」、静默放宽到 ≥5 s），应对末次进水后排水泵脉冲截断首轮扫描的场景。

### 6. spinHiE（最终脱水结束）

`P>300` 末段（间隔 ≤120 s 合并）；无 P>300 段时取最后一段 `P≥60` 活动段终点（不足放宽到 P≥20，覆盖烘干低功率尾段）。

### 7. opEnd（运行结束）

`spinHiE+30` 后首个连续 10 s `P<5`，且前 10 s 峰值 <100 W、前 40 s 峰值 >5 W。预检与回退：

- 平台预检：最后 ≥12 W 活动点后若存在 ≥300 s 连续 3~12 W 恒待机平台，取活动点后首个「其后 20 s 均 <12 W」样本（平台 = 洗后待机，不计入周期）；
- 尾段脉冲回退：尾段含周期性 ~5 W 脉冲时，取最后 ≥5 W 活动段之后的首个样本。

### 8. 0.5 s 采样降采样

平均采样间隔 <0.75 s 时才执行「每秒保留首样本」，保证所有索引阈值维持 1 Hz 语义，1 s 文件零影响。

## 开发 / 构建

- 源文件：`app.html`（依赖 `lib/xlsx.full.min.js`）
- 打包成单文件：
  `powershell -File build_software.ps1` → 生成 `洗衣机数据分析软件.html` 与 `启动洗衣机分析工具.bat`
- 本地静态服务器（端口 8765，便于浏览器调试 app.html）：
  `powershell -File server.ps1`

## 目录结构

```
app.html                    # 应用源文件
lib/xlsx.full.min.js        # Excel 解析库
洗衣机数据分析软件.html      # 打包后的单文件交付物
启动洗衣机分析工具.bat       # 双击启动器
build_software.ps1          # 打包脚本
server.ps1                  # 本地静态服务器
```
